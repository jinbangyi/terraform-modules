# Basic Usage Example

This directory contains a basic example of how to use the Terraform module.

## Usage

```bash
# Initialize Terraform
terraform init

# Plan the deployment
terraform plan

# Apply the configuration
terraform apply
```

## What this example demonstrates

1. **Basic Usage**: Using the module with default values
2. **Custom Configuration**: Providing custom values for module inputs
3. **Variable Usage**: Using Terraform variables to parameterize the module

## Clean up

```bash
# Destroy the created resources
terraform destroy
```
